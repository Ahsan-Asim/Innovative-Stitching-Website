# Innovative-Stitching-Website
Ahsan Stitching Website is a MERN stack-based online stitching center platform. It enables customers to explore clothing materials and designs, place and cancel orders, and manage carts. Admins can manage users and inventory, while tailors can track orders and get verified.



## 📌 Features

### 🛍️ Customer
- Account creation and email verification
- Browse designs with details (images, descriptions, prices)
- Add/remove items from the cart
- Place and cancel orders
- Leave feedback

### 🧵 Tailor
- Register and verify account
- View assigned orders (future scope)

### 👨‍💼 Admin
- Register and login
- Upload/manage materials and designs
- Add, update, delete tailors and customers
- View feedback and orders

## 🚀 Getting Started

- Node.js

### Installation

```bash

cd ahsan-stitching-website
npm install


Do:
PORT=5000
MONGODB_URI=your_mongo_connection_string
JWT_SECRET=your_secret_key
